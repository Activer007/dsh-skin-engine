# 人物皮肤单图替换：第一阶段

基线：main `7e273031250b218845711f5ed6e5fc3133588a92`。

## 范围与操作

支持 night-navigator、jade-archive、blue-arc、dawn-station、moonlit-horizon、crimson-rain 六个人物预设。详情页选择 PNG/JPEG/WebP，调整适应/填充、焦点位置、缩放和透明度；沿用现有聊天预览、应用、放弃修改流程。恢复内置图片也是草稿，需应用才持久保存。纯特效皮肤、多图层、独立编辑器不在本阶段。

每张图片最多 5 MiB，边长最多 4096，总像素最多 8 Mi。当前 DSH 主机个人 profile 下独立存储，不写入内置包、不改变 skin ID、收藏和最近使用记录。远程访问 DSH 时“本地”指 DSH 主机，不是浏览器所在电脑。

图片哈希命名并去重，每个 profile 最多保留 32 张（最多 160 MiB）。放弃草稿与恢复默认会保留文件。达到上限返回明确错误。导出皮肤时不导出私人图片或其引用，导入包也不能注入私人图片引用。

场景皮肤保留原安全区域、窄屏规则、遮罩和运动策略，焦点位置改变画面构图；缩略预览不是聊天布局的精确复刻。窄屏 opacity/scale 仍受原断点保护。丢失或无法解码的自定义图回退内置图。皮肤原有的光暗主题仍生效，但单张替换图片共用于两个主题。

### 管理个人图片

在支持 R2-ART-01 的版本中，打开「外观中心 → 皮肤管理 → 个人图片」，查看当前 Profile 已存图片的数量、容量、缩略图和保存位置。要移除一张图片，点击「删除」并确认。已保存的皮肤仍在使用时，请先在人物详情恢复内置图片并应用。当前窗口的未保存草稿也会保护图片，其他窗口的未保存草稿可能在删除后失去图片。

### 为新皮肤开放单图替换

Engine API 1.7.0 新增可选的 `customizable.artwork` 声明。皮肤可将一张随包主图开放为替换入口，原有插画仍随 ZIP 交付。

```json
{
  "engineApi": "^1.7.0",
  "customizable": { "artwork": { "slot": "primary" } }
}
```

主图使用 SceneSpec 的 `layout.artwork`，或使用旧式受控 CSS 的 `[data-dsh-skin-package-art]` 槽。两种方式都要求图片出现在 Manifest 的 `assets` 中。替换沿用原有场景的锚点、阅读留白和断点。用户偏好可以调整适应方式、焦点、缩放和透明度。双明暗变体共用用户选择的一张图。

从源码打包下面的浅色模板后，在外观中心导入 ZIP，即可在详情的「自定义皮肤」中试用。

```powershell
npm run pack:skin -- skin-sources/examples/templates/portrait-light .cache/artwork-sample
```

旧 ZIP 可继续导入。旧人物皮肤的已保存偏好按原 ID 读取，包回滚时也会保留偏好。私人图片及其引用仍留在当前 Profile。 [浅色模板源码](../skin-sources/examples/templates/portrait-light/skin.json)

## 开发拆分

1. 独立图片存储与读取，流式大小限制、类型/尺寸检查、哈希校验、路径与符号链接防护。
2. 扩展个人偏好，沿用已有版本冲突校验与锁，不写内置资源；只允许八个内置人物皮肤。
3. 详情页单图选择、调节、预览/应用/放弃/恢复；上传迟到结果不覆盖已变化的编辑状态。
4. 同皮肤换图重新准备渲染；图片缺失回退；保留场景安全布局。
5. 补存储、参数拒绝、渲染切换及回退测试；更新验收台账。

## 验收状态

自动化覆盖哈希去重、类型/尺寸和路径限制、符号链接、32 张上限、选择修订与空偏好、迟到上传、缺图回退和 ZIP 隐私。真实桌面实测范围、截图及复跑方式见 [阶段验收记录](user-artwork-stage1-validation.md)。

回装不支持个人图片字段的旧插件前，使用升级前备份的 Profile 选择文件。旧版本使用严格的偏好校验，读取新增图片字段时可能拒绝整个选择文件。图片目录独立保存，恢复内置图或原生外观均保留该目录。
