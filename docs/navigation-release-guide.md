## 当前主线的操作入口

| 操作 | 入口及行为 |
|---|---|
| 找皮肤、调皮肤特效、管理包 | 左侧「外观中心」，使用皮肤库、特效与性能、皮肤管理三页 |
| 修改参数 | 草稿在当前窗口跨导航保留；点击应用写入 Profile，插件卸载或窗口重启会清除未保存草稿 |
| 真实预览 | 点击「在聊天中预览」，返回原聊天，等聊天可见后开始约 30 秒的预览 |
| 取消或到期 | 点击聊天操作条的取消，或在「设置 → 皮肤引擎 → 紧急恢复」取消；到期恢复已保存外观。打开、关闭设置期间预览继续 |
| 应用 | 从外观中心或聊天操作条应用；收到修订冲突时复核当前保存值和草稿后重试 |
| 修改窗口特效 | 「设置 → 皮肤引擎 → 窗口效果」调整当前窗口的模式与质量。关闭窗口特效会保留已保存的皮肤和配色 |
| 故障恢复 | 在「设置 → 皮肤引擎」检查 Host 或二次确认恢复默认外观；恢复会清除已保存的皮肤选择，保留皮肤包和各皮肤偏好 |

包导入/更新期间可以离开外观中心；不要重复提交。取消后以 Host 回读为准，结果不确定应刷新核对，不能将取消提示当作服务端已撤销。草稿与已保存、当前渲染、临时预览是不同状态。

## 最终同候选矩阵

所有行 Web / Windows 分开记录；每项记录实际步骤、观察、截图/日志、候选与包哈希。人工观察不可用布尔常量或单测替代。

| 索引 | 执行内容与通过条件 |
|---|---|
| navigation | 单一侧栏入口；回到同一聊天；切换其他面板与折叠侧栏；按各宿主实际行为记录取消固定及重启；设置页使用原生宽度，皮肤编辑和管理可从外观中心进入 |
| state | 未保存草稿跨导航保留且 Host revision 不变；区分保存值、渲染值、预览值；Web 双窗口同 Profile 触发 409，验证草稿保护与 Host 回读；Windows 用隔离 Profile 的旧修订验证同一回读路径，记录采用的步骤；重启恢复已保存外观 |
| preview | 聊天和输入框可见后才开始；实际约 30 秒到期；取消、应用、导航回编辑；重复请求与加载中离开；打开、关闭设置保留预览，显式应急取消结束；切换全局面板或重启后检查临时预览已清理 |
| packages | 导入、更新、回滚、卸载、导出；导航时暂停上传并恢复，禁止重复写；取消后 staging 清理；Windows **真实原生保存**，验证文件存在且可解包、内容正确（不能用mock代替） |
| usability | 1280及760 CSS px，中英、深浅、forced-colors；Tab/方向键/Esc、可见焦点及返回；loading/error；动作条不遮挡输入，设置应急操作可达 |
| coexistence | 原生设置与已有全局浮层/背景基本让路；Worktable/Wallpaper 如未安装或未验，明确记录阻塞，不能标pass；不扩展为NAV08全面联合专项 |
| performance | 10/100包的图片懒加载与索引复用、空闲无新增常驻RAF；前台/后台采样保留工具方法和数据，不只截图；对照既有基线说明差异 |
| cleanup | 禁用时主面板自动回聊天、入口/动作条/自有样式清理、监听与计时器释放；旧加载/保存晚到不重新发布；复启无重复入口，临时宿主进程退出 |

## 证据索引与门禁命令

模板 `docs/navigation-release-evidence.json` 已记录 NAV05 和 SYS01 合并提交，最终候选和集成验收仍待填写。复制模板到验收输出目录，使用相对于索引文件的证据路径（或仅供本地使用的绝对路径）。保留最终索引的可分享副本。

```sh
node --test test/navigation-release-gate.test.mjs
node scripts/acceptance/navigation-release-gate.mjs /path/to/navigation-release-evidence.json
```

CLI 检查两项依赖的已合并声明和提交格式、候选审查与双端记录的候选 SHA、包哈希、指定的验收宿主版本、八类观察记录及证据文件是否齐全。它还会读取共同候选包并计算 SHA-256。精确宿主版本仅用于本矩阵基线。pending、blocked、waived 和未解决的 exceptions 均阻止最终完成。

**限制：** 这是证据完整性校验器，不执行 UI、不证明文件内容真实，也不验证 Git 祖先关系。LHA 必须另用 `git merge-base --is-ancestor <依赖提交> <候选提交>` 核实依赖已纳入候选，亲自审阅证据，运行完整 `verify:local`。没有真实证据时不要修改模板以得到绿色结果。
