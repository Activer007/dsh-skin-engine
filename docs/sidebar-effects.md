# 侧栏动态效果

入口：设置 → Skin Engine → 窗口效果 → **侧栏动态效果**。

- 默认关闭，保持原有皮肤表现。开启后，复用当前皮肤已有的同一个场景与调度器，不新建侧栏粒子系统。
- 偏好保存在当前应用/浏览器来源的 localStorage，适用于所有皮肤；不是服务端账号设置，不跨设备同步。存储不可用时仅本次会话有效，设置页会提示。
- 在已审计的宿主网格布局中覆盖展开和折叠侧栏；切换外观中心等全局面板时侧栏仍可显示氛围，但不将主面板、菜单、编辑器强制透明。
- 开启时使用 56% 侧栏色遮罩且不模糊背景，避免原玻璃层将浮尘、流光抹成纯色；文本和控件继续使用宿主样式。
- 开关遵循全局模式：静态模式停止动态；关闭/节能模式不启用新增侧栏透出。减少动态效果仍生效；减少透明度、强制色彩、抽屉和不兼容宿主布局安全回退。
- 纯静态皮肤不会凭空获得动态效果，场景立绘仍保留原本的聊天区域布局限制。

## 本地 DSH 人工验收

1. 记录 DSH、插件版本，应用 Deep Ocean，保持默认关闭，确认原来界面不变。
2. 在设置中打开侧栏动态效果。返回聊天页，检查浮尘、光晕延伸至左侧，文字与选中项清楚，按钮可以操作。
3. 展开→折叠→展开侧栏，进入外观中心→返回聊天，调整窗口大小；不得出现黑屏、背景闪断或重复叠层。
4. 换用浮光深境等其他动态皮肤。开关保持；只展示该皮肤已有的效果。更换皮肤、取消预览后不得残留上一皮肤背景。
5. 连续开/关 5 次；关闭恢复原表现。刷新确认设置仍在；切换静态、节能、关闭、系统减少动态/透明度设置，检查退化。
6. 开发者工具确认最多一个 `[data-dsh-skin-effect-scene]`，并检查控制台是否有渲染错误。性能对照可随集成里程碑执行。
7. 检查窄屏抽屉、未知布局不强行透明；如回退，请记录宿主 DOM/版本，不通过提升 z-index 绕过布局检查。

候选版 `1.10.2-sidebar.1` 已在隔离的 Windows DSH `0.2.2-rc.3` 验证。Deep Ocean 展开和折叠侧栏、外观中心均复用同一个场景与 Canvas。节能模式回退，刷新后保持开关，关闭恢复原侧栏。
