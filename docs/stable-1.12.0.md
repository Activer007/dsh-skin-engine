# 1.12.0 稳定版候选验收

候选基于 main 提交 `1a57311`，安装包由 `cb4d4dcf7c80d87fc62de87bffadba471c919b3c` 构建。引擎 API 为 1.9.0。两款 V2 仍使用各自的 0.2.0 独立 ZIP。

## 构建与校验

在 Node 24.16.0 下运行 `npm run verify:local -- trusted-commit cb4d4dcf7c80d87fc62de87bffadba471c919b3c`。构建、类型检查、lint 和 159 项测试通过。两份独立检出的引擎与 25 个样例归档逐字节一致。另用 `pack:skin` 的源码打包入口重建两份 V2 ZIP，两者各自与 Beta 1 发放的文件一致。

## 原地升级与回装

在官方 DSH 0.2.2-rc.5 的两个隔离配置安装同一份候选。每条路径先用旧版本保存经典 Deep Ocean 和夜航员的输入框透明度、夜航员测试图片，并导入浮光深境 VI。图片使用仓库内的样例素材。

| 宿主 | 升级、重启与回装 | 实拍 |
| --- | --- | --- |
| Windows Desktop | v1.11.4 原地升级后保留选择、透明度、个人图与浮光深境 VI。导入两款 V2，验证深海光境的常用调节与流光极幕光幕。回装 v1.11.4 前还原升级前选择快照，旧选中皮肤、偏好、个人图和原有 ZIP 均恢复。 | [升级后的个人换图](images/v1.12.0/windows-retained-artwork.webp) |
| Web | 公开 Beta 1 原地升级后保留以上数据及已导入的两款 V2，流光极幕的透明度可继续编辑。原地回装 Beta 1 后确认 V2 和本地包继续可用，并重新应用流光极幕及带自选图片的夜航员。 | [升级后的流光极幕](images/v1.12.0/web-aurora-v2.webp) |

两端分别核对三个版本阶段的实际 Client 和 Host 标识。两端页面错误均为零，本轮启动的测试宿主与浏览器均已退出。候选重启保留当前皮肤及按皮肤保存的偏好，窗口体验恢复「跟随皮肤」。恢复 DSH 原生外观后，按皮肤保存的偏好和三份导入包继续保留。实测比较了保存数据、包版本和修订，并确认自选图片文件字节一致、聊天中可以正常解码。

首次运行因为验收脚本使用了错误的英文控件名，等待深海光境的强度滑块超时。修正定位后，使用同一归档和新建隔离配置复跑通过。

实测以两条代表性路径覆盖两个官方宿主。性能与长时生命周期沿用 Beta 集成阶段的数据，候选验证集中在原地升级、偏好和回装。[验收结果与日志指纹](evidence/stable-1.12.0.json) · [Beta 专项结果](v2-beta-verification.md) · [备份与回滚](release-v1.md#回滚)
