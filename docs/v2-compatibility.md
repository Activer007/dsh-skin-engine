# V2 安装、兼容与回退

| Skin Engine | Engine API | Deep Ocean V2 0.1.0 / Aurora V2 0.1.0 | Deep Ocean V2 0.2.0 | Aurora V2 0.2.0 |
| --- | --- | --- | --- | --- |
| 1.11.4 正式版 | 1.7.0 | 支持两款 Alpha | 需要升级 | 需要升级 |
| PR #19 的 1.12.0 开发快照 | 1.8.0 | 支持 | 需要升级 | 支持 |
| 1.12.0-beta.1 预发行版 | 1.9.0 | 支持 | 支持 | 支持 |
| 1.12.0-beta.2 主线候选（常用调节） | 1.9.0 | 支持 | 支持 | 支持 |

对 PR #19 的实际 Host 构建导入光场声明时，声明最低 API 为 1.8 会得到兼容判定和 `unknown-effect` 诊断。将最低要求提高到 1.9 后，同一旧构建返回 `incompatible-engine`。因此 Ocean ZIP 要求 `^1.9.0`，Aurora ZIP 要求 `^1.8.0`。原版和 V2 分别保有自己的 ID、收藏与保存项。[双端共存记录](v2-coexistence.md)

## 升级和回退

1. 升级引擎前退出 DSH，并按[配置回退说明](release-v1.md#回滚)备份现有配置。重启后在外观中心确认客户端版本，在设置页检查 Host 版本。
2. 在皮肤管理选择已安装的 V2，使用「从 ZIP 更新」选择对应的 0.2.0 ZIP。首次安装使用皮肤库的导入入口。两个 ZIP 分别管理。
3. 若要恢复 Alpha，在皮肤管理选择刚更新的皮肤，点回滚到 0.1.0 并确认。原有关闭状态和强度仍按旧效果读取。回退整个引擎时先退出 DSH，恢复升级前的配置快照，再启动对应的发行版。

## 验证记录

官方 DSH Web 0.2.2-rc.5 隔离配置将 Ocean Alpha 的流光强度保存为零、开关关闭，浮尘保存为 57%。升级到 0.2.0 后，光场仍关闭且强度为零。首次编辑前导出的偏好使用新效果键。手动开启并保存 1% 后，回退 ZIP，旧流光仍关闭且为零，浮尘仍为 57%。测试实例已关闭。[原始结果摘要](evidence/v2-02-upgrade.json)

光场低、平衡、高画质预算最多为 2、4、5 束。光幕按相应画质使用 2、2、3 层及有界缓冲。两种效果均支持静态回退，场景负责暂停与清理。[光场实拍](deep-ocean-v2-lightfield.md) · [光幕实拍与验证](aurora-v2-curtain.md)
