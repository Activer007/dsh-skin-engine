# Skin Engine project history

This repository starts from a source snapshot before SceneSpec, then records 30 selected milestones from the private development archive. Each milestone is a snapshot of the integrated project, including intervening changes it depends on. PR numbers refer to the archive. The public release uses newly built archives and its own checksums.
