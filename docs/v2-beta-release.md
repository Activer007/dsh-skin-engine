# Skin Engine 1.12.0-beta.1 发布验收

引擎源提交为 `7413c20`，Engine API 为 `1.9.0`。发布提供一个引擎 TGZ 和两款可独立卸载的皮肤 ZIP。「深海光境」0.2.0 需要 API `^1.9.0`，「流光极幕」0.2.0 需要 `^1.8.0`。两个 ZIP 均从各自源目录重新打包，结果与双端实测文件逐字节一致。[素材来源和封面指纹](evidence/v2-beta-assets.json) · [发布文件 SHA-256 与双端结果](evidence/v2-beta-release.json)

## 官方宿主复验

隔离的 DSH Web 与 Windows Desktop 均为 `0.2.2-rc.5`。两个平台使用同一份最终 TGZ 和 ZIP，复验导入、五款皮肤切换、预览取消和自然到期、收藏、重启保留、独立卸载、长文本、代码及多行输入。页面错误均为零，测试会话均已关闭。

| 输入 | 两个平台的中英文界面结果 |
| --- | --- |
| Engine API 或 DSH 版本不匹配 | 皮肤可进入库，包管理提示更新相应组件或选择兼容版本，阻止应用 |
| 光场声明的最低 API 低于要求 | 导入失败，建议向作者索取兼容 ZIP，技术详情显示对应诊断码 |
| 已声明的封面缺失 | 导入失败，建议获取完整 ZIP 或核对资源路径 |
| ZIP 已损坏 | 导入失败，建议重新下载并导入原始文件 |
| 有未知可选特效 | 安装成功，皮肤详情说明该特效已跳过，已知特效仍可使用 |

100 次切换、300 秒后台和 P95 数据来自上一阶段固定归档。此后引擎只修改了兼容提示与错误呈现，Host、渲染器、计时器、参数和两款皮肤均沿用该候选。最终归档另做上述双端复验。[专项结果与实拍](v2-beta-verification.md) · [升级与偏好回退](v2-compatibility.md#升级和回退)

## 安装与回滚

在目标 profile 备份现有配置，按[各平台的安装步骤](release-v1.md#安装与启用)原地更新引擎并重启。打开外观中心确认引擎版本，再分别导入所需 ZIP。已装 Alpha 的用户从「皮肤管理」选择对应皮肤并从 ZIP 更新。可切回经典版、单独卸载某款 V2，或将升级过的皮肤回滚到上个版本。降级引擎时退出 DSH，恢复升级前的配置快照与相应引擎。
