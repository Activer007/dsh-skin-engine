# 01 · Product Requirements

## 1. 核心用户流程

### 安装与启用

1. 用户打开「设置 → 外观 → 皮肤管理」。
2. 看到已安装皮肤卡片、预览图、名称、版本、作者和兼容状态。
3. 选择皮肤，点击「预览」或「应用」。
4. 引擎加载 Manifest、Tokens、CSS 与 Effects Profile。
5. 完成宿主适配与效果挂载；失败时回滚到原皮肤。

### 预览与回滚

- 预览不立即覆盖用户长期选择。
- 预览模式显示明确的「正在预览」状态。
- 用户可点击「应用」确认，或「恢复」退出。
- 页面刷新或预览超时后回到上一个持久化皮肤。
- 引擎异常时优先恢复官方原生样式。

### 导入皮肤包

- 接受 `.dshskin.zip`。
- 先在 staging 目录解压，校验路径、大小、Manifest、CSS 与资源。
- 校验成功后原子移动到 skins 目录。
- 校验失败不污染已安装目录。

## 3. 皮肤包能力分级

- `tokens`：颜色、圆角、字体、阴影、间距。
- `css`：受限 CSS，必须作用于皮肤作用域。
- `assets`：本地图片、字体和图标。
- `effects:css`：调用 CSS Renderer 的内置效果。
- `effects:canvas2d`：调用 Canvas 2D 内置效果。
- `effects:webgl`：调用 WebGL 内置效果，默认关闭。

v1 不提供 `scripts`、`arbitrary-js`、`remote-code` 能力。

## 4. 非功能需求

- 皮肤切换无需整页刷新（若宿主的配置重组机制要求重载，则在 M0 明确并采用宿主支持的最小重载路径）。
- 任何皮肤都不得遮挡输入框、菜单、弹窗和键盘焦点。
- 用户关闭动态效果后，所有持续动画停止。
- 所有资源使用相对路径，不依赖第三方 CDN。
- 支持 DSH 深浅色模式；可声明 `color-scheme: light / dark / both`。
- 管理器 UI 与皮肤视觉效果分离，避免皮肤无法切换时连管理器也不可用。

## 5. 用户可调参数

v1 面向普通用户只展示少量全局参数：

- 视觉强度：低 / 标准 / 高。
- 动态效果：开 / 关。
- 玻璃模糊：0–24 px。
- 环境动画速度：0.1–1.0。
- 粒子密度：0–1。
- 交互效果：开 / 关。
- 性能模式：自动 / 节能 / 平衡 / 高品质。

高级参数保留在皮肤作者的 `effects.json` 中，不在 v1 做复杂的通用节点编辑器。
