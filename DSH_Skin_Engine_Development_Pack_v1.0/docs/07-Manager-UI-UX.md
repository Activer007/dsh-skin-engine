# 07 · Skin Manager UI/UX

## 1. 页面结构

入口：`设置 → 外观 → 皮肤管理`。

建议页面采用「左侧分类 + 中央皮肤画廊 + 右侧详情」布局：

- 顶部：当前皮肤、性能档、动态效果总开关。
- 左侧：全部 / 已安装 / 内置 / 导入。
- 中央：皮肤卡片、预览图、名称、标签、版本和兼容状态。
- 右侧：选中皮肤的预览图、描述、效果组合和参数。

## 2. 皮肤卡片

每张卡片展示：

- 预览图（light / dark）。
- 名称、作者、版本。
- 视觉标签：Glass / Minimal / Aurora / Neon 等。
- 当前状态：已应用 / 可预览 / 不兼容 / 安装损坏。
- 操作：预览、应用、详情。

## 3. 详情页

分为三组：

1. **Appearance**：主色、字体、圆角、阴影、密度。
2. **Effects**：Glass、Aurora、Dust、Light Flow 等效果开关和强度。
3. **Performance**：自动 / 节能 / 平衡 / 高品质。

不把 30 个技术参数全部暴露给普通用户。高级设置可以折叠。

## 4. 交互规则

- Preview：临时应用，不写入长期 active skin。
- Apply：确认应用并持久化。
- Reset：重置当前皮肤的用户覆盖参数，不删除皮肤包。
- Remove：卸载皮肤；若当前正在使用，先回到 Default。
- Import：选择 `.dshskin.zip`，显示校验过程和错误原因。
- Export：导出包本体与可选用户配置；默认不包含用户私有素材。

建议管理器使用本包 `09-skin-manager-ui-concept.png` 作为布局参考；具体颜色与组件要遵循 DSH 当前设计系统，不把概念图中的布局当作宿主真实结构。
